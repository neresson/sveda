# @sveda-ai/element

Web component `<sveda-chat>` for embedding Sveda without a frontend framework.

Docs: [sveda.dev/docs/hosts/vanilla](https://sveda.dev/docs/hosts/vanilla)

```bash
npm install @sveda-ai/element
```

```html
<link rel="stylesheet" href="node_modules/@sveda-ai/element/dist/sveda-chat.css" />
<script type="module" src="node_modules/@sveda-ai/element/dist/sveda-chat.js"></script>
<sveda-chat origin="https://your-sveda-origin" token="embed-token"></sveda-chat>
```
