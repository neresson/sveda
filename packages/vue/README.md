# @sveda-ai/vue

Vue 3 SDK for Sveda — `<SvedaChat>`, composables, and the default UI theme.

Docs: [sveda.dev/docs/chat-ui/vue](https://sveda.dev/docs/chat-ui/vue)

```bash
npm install @sveda-ai/vue
```

Peer dependency: `vue@^3.5`.
