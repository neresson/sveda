# Privacy Policy — Sveda

Sveda for iOS and the web embed are clients for a **Sveda server that you choose**. The Sveda project does not operate a public chat backend for the iOS app. Messages you send go to the server URL you enter.

## Data on the device

The iOS app may store:

- the server URL (App Storage)
- the access key and embed token (iOS Keychain, this device only)
- a random visitor identifier (Keychain), so chat history stays attached to this install

That identifier is sent with chat requests so the server can load your threads.

## Data on the server

Chat content is processed for app functionality. The operator of the server you connect to is the controller of data stored there. Sveda does not sell chat content, use it for advertising, or track you across apps or websites.

## Controls

You can delete individual chats from history. In the iOS app, **Settings → Reset this device** deletes chats for this visitor on the current server (when it is reachable) and clears local credentials and the visitor identifier.

## Assistant output

Model replies may be inaccurate or harmful. They are not professional advice. Links inside replies are produced by the server you connected to.

## Contact

Questions about the iOS app: the App Store support listing for Sveda. Questions about chats stored on a server: that server’s operator.
